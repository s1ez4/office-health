# Office Health

Приложение для офисных компьютеров на **Windows и Mac**: проверяет износ железа и показывает в одной панели
статус каждого компьютера — **«Норм» / «Скоро менять» / «Срочно»** — с советами, что делать.

- Один файл, без установки и без интернета.
- **Ваш компьютер** проверяется сам при запуске и каждые 6 часов, пока приложение открыто.
- **Другие компьютеры** добавляются по приглашению как «агенты»: сами проверяют себя каждые 6 часов
  и присылают результат вам. **Агенты ничего не видят** — ни свой статус, ни чужие. Панель открывается
  только на компьютере владельца.
- История проверок: видно, растёт ли число плохих секторов от проверки к проверке.

## Что проверяет

| Что | Windows | Mac | «Скоро менять» | «Срочно» |
|---|---|---|---|---|
| HDD: плохие сектора (SMART 5 + 197 + 198) | smartctl | smartctl | > 0 | > 50 или SMART FAILED |
| SSD / NVMe: израсходованный ресурс | smartctl | smartctl | ≥ 80% | ≥ 95% или SMART FAILED |
| Общий вердикт диска, если нет smartctl | — | diskutil | — | SMART Failing |
| Батарея: сколько держит от новой | WMI | ioreg | < 60% | < 40% |
| Ошибки железа за 30 дней | WHEA в журнале System | отчёты kernel panic | WHEA ≥ 1 / паник ≥ 1 | WHEA ≥ 10 / паник ≥ 3 |
| Раздел заполнен (не износ, но полезно) | gopsutil | gopsutil | > 90% | — |

Пороги — константы в начале `rules/rules.go`. Общий статус компьютера — худший из всех; если диск
не удалось прочитать, рядом будет пометка «не всё удалось проверить».

## Как пользоваться

### Windows

1. Распакуйте `OfficeHealth-windows.zip`, например в `C:\office-health`.
2. Поставьте **smartmontools** (без него не проверить диски): `winget install smartmontools.smartmontools`
   в командной строке от администратора, или положите `smartctl.exe` рядом с `office-health.exe`.
3. Запустите `office-health.exe` (лучше правой кнопкой → «Запуск от имени администратора»).
   Откроется браузер с панелью. Чёрное окно не закрывайте — это и есть работающее приложение;
   выключить — кнопкой «Выключить» в панели.

### Mac

1. Распакуйте `OfficeHealth-mac.zip`, перетащите **Office Health** в «Программы».
2. Программа не подписана Apple, поэтому первый раз выполните в Терминале:
   `xattr -cr "/Applications/Office Health.app"` (подробно — в «Как открыть.txt» в архиве).
3. Откройте Office Health — появится панель в браузере. Значка в Доке нет; выключить — кнопкой «Выключить».
4. Для подробной проверки диска: `brew install smartmontools` (иначе — только «исправен / неисправен»).

### Добавить другой компьютер

1. В панели: **«Добавить компьютер» → «Создать приглашение»**. Появится одноразовый код `OH1-…` (живёт 7 дней).
2. На другом компьютере (там должна лежать та же программа):
   - **Windows**, командная строка от администратора: `office-health.exe join OH1-…`
   - **Mac**, Терминал: `"/Applications/Office Health.app/Contents/MacOS/office-health" join OH1-…`
   - или откройте там Office Health → «Добавить компьютер» → вставьте код в нижний блок «Этот компьютер — агент другого?».
3. Компьютер появится в панели через несколько секунд. Дальше он сам отправляет проверку каждые 6 часов
   (Windows — задача `office-health-agent` в Планировщике, нужен запуск от администратора; Mac — launchd).

Условия: оба компьютера **в одной локальной сети**, приложение у владельца **запущено**. Windows при первом
приглашении может спросить, разрешить ли office-health доступ к сети, — разрешите для частных сетей.

Отключить агента: `office-health leave`. Убрать компьютер из панели: страница компьютера → «Настройки компьютера» →
«Убрать» — его ключ перестанет действовать.

## Команды

```
office-health                 приложение (панель в браузере) — то же, что двойной щелчок
office-health app --demo      приложение с выдуманными компьютерами — посмотреть, как всё выглядит
office-health join <код>      подключить этот компьютер агентом
office-health agent           проверить и отправить владельцу (так его вызывает расписание)
office-health leave           отключить этот компьютер от владельца
office-health report [--demo] [--out папка] [--quiet]   разовый HTML-отчёт в файл (как в первой версии)
```

У `app` есть флаги `--port` (панель, по умолчанию 8765), `--agent-port` (приём от агентов, 8766),
`--data` (папка с данными) и `--no-browser`.

Данные приложения: Windows — `%AppData%\office-health`, Mac — `~/Library/Application Support/office-health`.
Настройки агента: Windows — `C:\ProgramData\office-health\agent.json`, Mac — там же, где данные.

## Безопасность

- Панель слушает только `127.0.0.1:8765` — с другого компьютера её не открыть. Дополнительно проверяется
  заголовок Host (защита от DNS rebinding) и Origin у кнопок (чужой сайт не нажмёт их из вашего браузера).
- Порт для агентов (`8766`) открывается, только когда есть приглашение или добавленный компьютер.
  На нём два действия: подключиться по одноразовому коду и прислать снимок по своему ключу. Ничего не отдаёт.
- Коды приглашений и ключи агентов хранятся только в виде хешей SHA-256 и сравниваются за постоянное время.
- Внутри локальной сети данные идут по HTTP без шифрования (для офисной сети приемлемо; для интернета —
  этап «сервер-посредник» с HTTPS).

## Сборка

Нужен [Go](https://go.dev/dl/) 1.27.

```
go run ./tools/pack     # → dist/OfficeHealth-mac.zip и dist/OfficeHealth-windows.zip
go test ./...           # тесты
go run . app --demo     # посмотреть приложение на выдуманных данных
```

`tools/pack` работает и на Windows: собирает программу под Mac (Intel и Apple M) и склеивает
в одну универсальную, делает `Office Health.app` с иконкой. Утилиты Apple не нужны.

## Как устроен код

```
main.go               подкоманды: app, join, agent, leave, report
collect/              СБОР: Snapshot и интерфейс Collector
  system.go             общее (gopsutil)          disks.go       smartctl (все ОС)
  battery_windows.go    WMI                       errors_windows.go  WHEA через Get-WinEvent
  platform_darwin.go    Mac: ioreg, diskutil, kernel panic   mac_parse.go  разбор их ответов (тестируется везде)
  platform_*.go         что есть на какой ОС      demo.go        выдуманный компьютер
rules/rules.go        ПРАВИЛА: пороги и советы
report/               ОТЧЁТ: HTML-шаблон (используется и в файле, и в панели)
store/store.go        ХРАНИЛИЩЕ: компьютеры, приглашения, история (JSON-файлы)
app/                  ПРИЛОЖЕНИЕ: веб-сервер, страницы (ui/*.html), приём от агентов
agent/                АГЕНТ: код приглашения, отправка, расписание (Планировщик / launchd)
tools/pack/           сборка архивов для раздачи
```
