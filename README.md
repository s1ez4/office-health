# office-health

Маленькая программа для Windows-компьютеров в офисе: проверяет износ железа и сохраняет понятный HTML-отчёт
со статусом **«Норм» / «Скоро менять» / «Срочно»** и советами, что делать.

Один файл `office-health.exe`, без установки, без интернета, без сервера.

## Что проверяет

| Что | Откуда | «Скоро менять» | «Срочно» |
|---|---|---|---|
| Жёсткий диск (HDD): плохие сектора — атрибуты SMART 5, 197, 198 | smartctl | сумма > 0 | сумма > 50 или SMART FAILED |
| SSD / NVMe: израсходованный ресурс записи | smartctl | ≥ 80% | ≥ 95% или SMART FAILED |
| Батарея ноутбука: сколько держит от новой | WMI | < 60% | < 40% |
| Ошибки железа (WHEA) в журнале Windows за 30 дней | журнал System | ≥ 1 | ≥ 10 |
| Заполненность разделов C:, D: … (не износ, но полезно) | Windows | > 90% | — |

Ещё в отчёте: имя ПК, Windows, процессор, память, время без перезагрузки, наработка дисков в часах,
сколько терабайт записано на SSD. Пороги — константы в начале `rules/rules.go`.

Общий статус компьютера — худший из всех. Если какой-то диск прочитать не удалось, рядом с общим статусом
будет пометка «не всё удалось проверить».

## Как собрать

Нужен [Go](https://go.dev/dl/) 1.27 (как записано в `go.mod`; Go версии 1.21+ сам докачает нужную).

```powershell
# в папке проекта, на Windows (PowerShell)
$env:GOOS="windows"; $env:GOARCH="amd64"; go build -trimpath -ldflags "-s -w" -o office-health.exe .
```

```bash
# на Mac или Linux — та же программа для Windows
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o office-health.exe .
```

- `GOOS` / `GOARCH` — под какую систему и процессор собирать (Go умеет собирать для Windows, даже сидя на Mac);
- `-ldflags "-s -w"` — выкинуть отладочную информацию, файл станет меньше;
- `-trimpath` — не вшивать в программу пути к папкам на компьютере разработчика.

Посмотреть отчёт, не имея Windows: `go run . --demo` — выдуманный компьютер (здоровый SSD, умирающий HDD,
батарея 55%, 3 ошибки WHEA). Тесты: `go test ./...`.

## Как запустить на офисном компьютере

1. Создайте папку `C:\office-health` и скопируйте туда `office-health.exe`.
2. Поставьте **smartmontools** (без него диски не проверить — остальное работает). Любой способ:
   - в командной строке от администратора: `winget install smartmontools.smartmontools`;
   - или установщик с сайта smartmontools.org (Download → Windows);
   - или просто положите `smartctl.exe` (из папки `C:\Program Files\smartmontools\bin` на любом компьютере)
     рядом с `office-health.exe`.
3. Нажмите на `office-health.exe` **правой кнопкой → «Запуск от имени администратора»**.
   Без администратора программа тоже работает, но некоторые диски Windows не даст прочитать —
   программа об этом предупредит.
4. Отчёт откроется в браузере сам. Файлы лежат в `C:\office-health\reports\`:
   - `office-health_ИМЯ-ПК_2026-11-20_1951.html` — отчёт;
   - `office-health_ИМЯ-ПК_2026-11-20_1951.json` — все данные (пригодятся для истории и графиков).

Флаги:

| Флаг | Что делает |
|---|---|
| `--demo` | выдуманные данные — посмотреть, как выглядит отчёт |
| `--out ПАПКА` | куда сохранять отчёты (по умолчанию `reports` рядом с программой) |
| `--quiet` | не открывать отчёт и не ждать Enter — для Планировщика задач |
| `--help` | подсказка по флагам |

## Запуск раз в день через Планировщик задач

### Одной командой

Откройте командную строку **от администратора** и выполните:

```
schtasks /Create /TN "office-health" /TR "\"C:\office-health\office-health.exe\" --quiet" /SC DAILY /ST 12:00 /RU SYSTEM /RL HIGHEST /F
```

- `/SC DAILY /ST 12:00` — каждый день в 12:00 (выберите время, когда компьютер обычно включён);
- `/RU SYSTEM /RL HIGHEST` — от имени системы с полными правами: не нужен пароль, работает,
  даже если никто не вошёл в Windows;
- `/F` — если задача уже есть, перезаписать.

Проверить сразу: `schtasks /Run /TN "office-health"` — через несколько секунд в `C:\office-health\reports`
появится новый отчёт. Удалить задачу: `schtasks /Delete /TN "office-health" /F`.

### Мышкой

1. Пуск → «Планировщик заданий» → справа «Создать задачу…» (не «простую»).
2. Вкладка **Общие**: имя `office-health`; «Изменить…» → впишите `SYSTEM` → ОК;
   отметьте «Выполнить с наивысшими правами».
3. **Триггеры** → «Создать…» → «Ежедневно», время, ОК.
4. **Действия** → «Создать…» → Программа: `C:\office-health\office-health.exe`,
   Аргументы: `--quiet`, ОК.
5. **Условия**: снимите «Запускать только при питании от электросети» (для ноутбуков).
6. **Параметры**: отметьте «Немедленно запускать задачу, если пропущен плановый запуск» —
   если в 12:00 компьютер был выключен, проверка пройдёт при включении.

Отчёты копятся в `reports` — по одному в день, это немного (≈10 КБ на отчёт).

## Как устроен код

```
office-health/
  main.go                 запуск: флаги, сбор → правила → отчёт
  launch_windows.go       двойной щелчок: открыть отчёт и подождать Enter
  launch_other.go         то же для Mac/Linux
  collect/                СБОР ДАННЫХ
    collect.go            Snapshot (все данные) и интерфейс Collector («сборщик»)
    types.go              структуры: диски, батарея, ошибки
    system.go             имя ПК, ОС, процессор, память, разделы (gopsutil, любая ОС)
    disks.go              диски через smartctl (любая ОС)
    battery_windows.go    батарея через WMI
    errors.go             разбор журнала ошибок (общая часть)
    errors_windows.go     WHEA через PowerShell Get-WinEvent
    platform_windows.go   список сборщиков для Windows, проверка администратора
    platform_other.go     то же для остальных ОС
    demo.go               выдуманный компьютер для --demo
    testdata/             образцы ответов smartctl для тестов
  rules/rules.go          ПРАВИЛА: пороги и советы
  report/                 ОТЧЁТ
    report.go             HTML + JSON
    template.html         шаблон (вшивается в .exe через go:embed)
```

Файлы `*_windows.go` попадают в программу только при сборке под Windows (build tags).
Чтобы добавить Mac, нужно создать `*_darwin.go` со своими сборщиками (батарея через
`ioreg -rn AppleSmartBattery`, kernel panic из `/Library/Logs/DiagnosticReports`) и поправить метку
в `platform_other.go` на `//go:build !windows && !darwin`. Диски через smartctl уже работают на Mac.

Зависимости: `gopsutil`, `yusufpapurcu/wmi`, `golang.org/x/sys` (проверка администратора; её всё равно
тянет gopsutil). Всё остальное — стандартная библиотека Go.
